# AGENTS.md

## Project Identity

This repository is part of the Blackfong portfolio.

Blackfong is the maker's mark for local-first software, offline-first systems, operator tools, and AI-assisted desktop infrastructure.

Do not make the project sound like a generic tutorial app. Keep the identity practical, technical, and restrained.

## Working Rules

- Do not push directly to main.
- Work on a named branch.
- Keep changes small and reviewable.
- Preserve the project’s current direction unless explicitly told otherwise.
- Prefer simple, maintainable code over clever code.
- Do not introduce cloud dependencies unless asked.
- Do not remove existing documentation without replacing it with something clearer.
- Update README.md when behavior, setup, commands, or project purpose changes.
- Add or update docs/ files when the explanation becomes too long for README.md.

## Portfolio Standards

Every repo should clearly answer:

1. What is this?
2. Why does it exist?
3. What problem does it solve?
4. How do I run it?
5. What technologies does it use?
6. What is complete now?
7. What is planned next?

## Code Standards

- Favor Python standard library where reasonable.
- Keep local-first behavior.
- Keep data local unless explicitly instructed otherwise.
- Use clear names.
- Avoid unnecessary dependencies.
- Add tests when modifying logic.
- Do not hide errors silently.

## Documentation Tone

Tone should be:

- clear
- technical
- recruiter-friendly
- confident
- not overly mythological
- not childish
- not vague

Blackfong identity is allowed, but practical explanation comes first.

## Preferred README Structure

1. Project name
2. One-sentence summary
3. What it is
4. Why it exists
5. Features
6. Tech stack
7. Quick start
8. CLI/API usage
9. Screenshots
10. Status
11. Roadmap
12. Portfolio note
