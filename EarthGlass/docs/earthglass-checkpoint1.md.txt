# EARTHGLASS_CHECKPOINT_001

## Status

Project paused.

EarthGlass is intended to be a standalone local-first geospatial intelligence dashboard.

No integration with:

* OBEOS
* Nightwatch
* QuietDrop
* 3000
* Blackfong event systems

at this stage.

The goal is to build EarthGlass independently first.

## Vision

EarthGlass is a local-first digital Earth viewer.

Initial focus:

* Earthquake events
* Geospatial visualization
* Interactive map
* Local data storage
* Layer-based architecture

Future possibilities:

* Weather
* Air quality
* Wildfires
* Environmental monitoring
* Satellite-derived datasets
* 3D globe

Not currently planned:

* AI
* LLM integration
* OBEOS integration
* Agent orchestration
